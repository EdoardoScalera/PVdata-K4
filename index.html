About the dashboard

This dashboard gives a compact view of the photovoltaic system performance and the current operating scenario.

Data is collected from the PV, load, irradiance, and weather sources by a local logging pipeline and stored in the repository as structured text files. The real-time view reads the latest dashboard snapshot, while the download section lets you export selected datasets for a chosen date range as CSV files or a ZIP archive.
